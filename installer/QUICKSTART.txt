SIGMA Desktop - test installers

CHOOSE YOUR DOWNLOAD
- macOS AppleSilicon: M-series Macs, macOS 14 or later; CPU/MPS.
- macOS Intel: Intel Macs, macOS 14 or later; defaults to CPU.
- Windows x64 CPU: 64-bit Intel/AMD Windows 10/11; no CUDA setup required.
  This is not a Windows ARM64 build. NVIDIA acceleration is not included.

INSTALL AND OPEN
1. Double-click the PKG (Mac) or EXE (Windows) installer.
2. Follow the installer. Installing the private runtime may take several minutes.
3. Open "SIGMA" from Applications (Mac) or Start/Desktop (Windows).
4. The SIGMA panel opens automatically. Use Open File or drag a TIFF into napari.
5. Check channel, time, Z and physical pixel sizes before analysis.

You do not need Python, conda, pip, or a terminal. The installer works offline.
The installed runtime occupies more space than the compressed download.
Intel Mac uses an older compatible PyTorch/NumPy combination; results across
different devices or dependency versions are not promised to be bit-identical.

SECURITY
These are unsigned test installers, not notarized/certified releases. macOS
Gatekeeper or Windows SmartScreen may block them. Do not disable those controls;
use your organization's approval process if needed.

LOGS
- Mac: ~/Library/Logs/SIGMA/desktop.log
- Windows: %LOCALAPPDATA%\SIGMA\logs\desktop.log
Startup failures show a dialog with details and the log location.

UNINSTALL
- Windows: Settings > Apps > Installed apps > SIGMA > Uninstall.
- Mac: close SIGMA; remove its application shortcut and its private runtime
  (~/Library/sigma-0.0.5 for a user install, /Library/sigma-0.0.5 for a system
  install). Do not delete your image or result folders.

UPDATES
Close SIGMA and uninstall an older desktop build before installing its replacement.
Older test builds used the application name "SIGMA 0.0.5"; remove that shortcut too.
The app/shortcut name is now always SIGMA; internal version metadata is retained.
Do not update individual Python packages inside this tested desktop runtime.
