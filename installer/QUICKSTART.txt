SIGMA Desktop - test installers

CHOOSE YOUR DOWNLOAD
- macOS AppleSilicon: M-series Macs, macOS 14 or later; CPU/MPS.
- macOS Intel: Intel Macs, macOS 14 or later; defaults to CPU.
- Windows x64 CPU: 64-bit Intel/AMD Windows 10/11; no CUDA setup required.
  This is not a Windows ARM64 build. NVIDIA acceleration is not included.

INSTALL AND OPEN
1. Mac: open the DMG and drag SIGMA.app to Applications, then eject the DMG.
   Python and all analysis dependencies are inside SIGMA.app, not /Library.
   You may also copy the complete app to your personal Applications folder.
   Windows: double-click the EXE and follow the installer.
2. Windows runtime installation may take several minutes. Mac needs only copying.
3. Open "SIGMA" from Applications (Mac) or Start/Desktop (Windows).
4. The SIGMA panel opens automatically. Use Open File or drag a TIFF into napari.
5. Check channel, time, Z and physical pixel sizes before analysis.

The window title bar and the panel's own title bar both read:
SIGMA (Structurely-aware Intensity-ordered GMM-MRF Algorithm).
The application, Dock and shortcut names remain SIGMA, without a version suffix.
The disk image and its mounted volume carry the SIGMA icon; Finder may still show
a generic icon on the downloaded .dmg file, because that icon is metadata a
download cannot carry.

You do not need Python, conda, pip, or a terminal. The installer works offline.
The installed runtime occupies more space than the compressed download.
Intel Mac uses an older compatible PyTorch/NumPy combination; results across
different devices or dependency versions are not promised to be bit-identical.

CHART STARTUP
SIGMA includes its chart fonts and a ready-to-use font index. It does not scan
your computer's system fonts. A deleted/corrupt user font cache is restored from
the app. Chart modules still load in the background, keeping the interface usable.
Charts use bundled DejaVu/STIX fonts; arbitrary system fonts and Chinese chart
labels need a separately supplied font. Normal application UI fonts are unchanged.

SECURITY
These are unsigned test installers, not notarized/certified releases. macOS
Gatekeeper or Windows SmartScreen may block them. Do not disable those controls;
use your organization's approval process if needed.

LOGS
- Mac: ~/Library/Logs/SIGMA/desktop.log
- Windows: %LOCALAPPDATA%\SIGMA\logs\desktop.log
Startup failures show a dialog with details and the log location.

UNINSTALL
- Windows: Settings > Apps > Installed apps > SIGMA > Uninstall.
- Mac DMG app: quit SIGMA, then move SIGMA.app from Applications to the Trash.
  This removes the app and its entire Python/analysis runtime together.
  Preferences, logs and caches remain in ~/Library/Application Support/SIGMA,
  ~/Library/Logs/SIGMA and ~/Library/Caches/SIGMA; remove those separately only
  if you want to erase settings/logs/caches too. Never delete image/result folders.
- Older PKG builds stored their runtime in ~/Library/sigma-0.0.5 (user install)
  or /Library/sigma-0.0.5 (system install). This new app neither uses nor deletes
  those old directories. They require a separate, deliberate legacy cleanup.

UPDATES
Quit SIGMA before replacing it. Mac: drag the new app into Applications and choose
Replace. Windows: uninstall the older desktop build, then install its replacement.
Older PKG builds used an external runtime; see the legacy cleanup note above.
The app/shortcut name is now always SIGMA; internal version metadata is retained.
Do not update individual Python packages inside this tested desktop runtime.
